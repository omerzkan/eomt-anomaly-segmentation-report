\section{Conclusion}
\label{sec:conclusion}

In this work, we studied semantic segmentation and anomaly segmentation for road-scene by comparing EoMT and ERFNet models.
We fine-tuned EoMT-COCO on Cityscapes validation dataset using frozen-backbone, and evaluated using four anomaly scoring functions on five benchmarks.
Results showed us that fine-tuning recovers most of the performance gap between COCO-pretrained model and the native Cityscapes model.
In ongoing experiments, we saw that EoMT consistently ourperforms ERFNet in anomaly detection. 
Overall, these results suggest that mask classification is a better option for safety-critical systems that require both semantic understanding and anomaly detection.
